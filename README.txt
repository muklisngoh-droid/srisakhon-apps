แอปมือถือ/คอมพิวเตอร์ (PWA) ของระบบบริหารการเงิน รพ.ศรีสาคร
1) แก้ไฟล์ config.js ใส่ลิงก์ Web app (/exec) ของแต่ละระบบ
2) อัปโหลดทั้งโฟลเดอร์นี้ขึ้น GitHub Pages (ฟรี) ตามคู่มือในแชต
3) ใส่ลิงก์หน้าเว็บนี้ใน Script property ชื่อ APP_HOME ของทุกระบบ เพื่อให้ปุ่ม "ติดตั้งเป็นแอป" ในแต่ละระบบพาไปหน้าติดตั้งได้
